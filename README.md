# Iron Man Armor Mod

Add Iron Man armor to Minecraft with flight capabilities.

## Features

- Adds Iron Man armor to the game
- Enables flight when wearing the armor

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/iron-man-armor-mod/releases)
2. Place the mod file in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

1. Craft or obtain the Iron Man armor
2. Equip the armor to enable flight

No additional configuration is required.
